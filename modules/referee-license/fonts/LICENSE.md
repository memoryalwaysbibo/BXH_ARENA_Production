# BXH referee Kai fallback

Source: **數位發展部 CNS11643 全字庫** — `TW-Kai.ttf` from the official `Fonts_Kai.zip` dataset.

- Dataset: https://data.gov.tw/dataset/5961
- Publisher: https://www.cns11643.gov.tw/
- Original package: https://data.cns11643.gov.tw/opendata/Fonts_Kai.zip
- Selected license: **政府資料開放授權條款第 1 版** (Open Government Data License, version 1.0), https://data.gov.tw/license

The bundled font is a subset containing the approved nine referee rank titles. Its font family was renamed `BXH Kai Preview`; the original copyright metadata remains in the font. CSS exposes this subset as `BXH Referee Kai`. This is the CNS11643 regular Kai fallback, not Microsoft's DFKai-SB or Apple's BiauKai. Devices with an installed 標楷體 use that local font first.
