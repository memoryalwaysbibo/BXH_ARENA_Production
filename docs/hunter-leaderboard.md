# 獵人榜

2026-10-27 黑爸要求製作。入口為既有排行榜中的「天梯榜／獵人榜」切換。

- 排序：目前獵人階級由高至低；同階比較顯示到小數一位的評級分。同階同分並列（1、1、3）。不以隱藏小數、勝場或登入順序拆開同名次。
- 顯示：公開玩家名稱、目前階級、評級分、最近 20 場實力分、生涯最高（歷史回算）、本人名次、更新時間及核對範圍。
- 資料：後端統一以既有可信執照 reader 核算正式個人積分賽，包含「大型可滿足中型以上」規則。每 6 小時更新；此榜是不同時間完成的核算結果，不是即時計分或單一資料庫瞬間快照。
- 完整性：失敗及歷史缺口保留待核對數，未有有效戰績及未有公開名稱分開列計。未完成全範圍核對不宣告全服最高。公開名稱範圍之外的玩家不推斷階級。
- 分頁：每頁 50 位，後續頁綁定同一 generation；重新整理會切至最新版本。本人名次由後端依登入身分取得。換帳號忽略前帳號尚未回覆的請求。
- 生涯最高是歷史回算；不宣稱已永久授予，不改既有授予及比賽資料。

後端配套：`release/hunter-leaderboard` 的 `getHunterLeaderboard` 與統一核算工作。未發布或服務異常時明確顯示無法讀取，不當作 0 人榜。新增測試 `node --test tests/hunter-leaderboard.test.cjs`。
