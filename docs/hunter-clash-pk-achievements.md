# 獵人交鋒：PK 專屬成就第一版

政策版本：`arena-pk-achievements-v1`。從後端更新後新建立的對戰開始計算；既有房間、歷史紀錄與舊實驗資料不回填。

| 徽章 | 條件 |
| --- | --- |
| 初次交鋒 | 累積 1 場符合資格的 PK |
| 交鋒新秀 | 累積 10 場 |
| 百戰獵人 | 累積 100 場 |
| 廣結戰友 | 與 5 位不同對手完成符合資格的 PK |

只計雙方確認結案且回合資料完整的對戰。每個台灣日期前 10 場、同對手前 6 場可計入；額度以結案順序決定，同一房間多場依場次順序計入。結案日期決定額度歸屬，午夜重置每日額度，生涯累積不重置。不符合額度的比賽仍保存 PK 戰績。

每位玩家的 `arenaPKPlayers/{uid}/achievementDays/{day}` 保存獨立計數，在與雙方比分帳本相同的交易中寫入；帳本各場保存 `pkAchievement` 版本、日期、當日序號、同對手序號及是否計入。交易重試與結案重送不會重複增加；不同房間同時結案由 Firestore 交易序列化計數。計數損壞時整筆結案拒絕，不會部分發放 XP 或紀錄戰績。

前端由完整分頁帳本推導徽章與進度，以賽事／場次去重。載入不完整、失敗或切換帳號時不顯示假的零進度或沿用另一帳號徽章。生涯徽章不受期間篩選影響。撤銷後排除該筆對戰，重新判定解鎖資格；當日額度不返還。

顯示入口為「我的 PK 戰績」及「獵人檔案 → 成就」。這四個徽章與既有永久成就分開，不新增 XP、稱號、正規階級或正式實力。練習 XP 暫停不影響徽章計數；既有 XP 發放規則維持獨立。

驗證涵蓋舊房間排除、每日與同對手上限、雙方結案、撤銷／重送、午夜、門檻、不同對手、損壞計數的原子回滾，以及實際 Auth／Firestore 模擬器中的跨房間並行結案。瀏覽器驗證手機歷史頁、雙方帳號隔離及窄螢幕排版。

## 第二批：勝場成就

| 徽章 | 條件 |
| --- | --- |
| 初嚐勝果 | 累積 1 場符合資格的勝場 |
| 十勝獵人 | 累積 10 場符合資格的勝場 |

沿用第一批政策版本與每日／同對手額度，以完整帳本中通過資格的 `isWin` 推導勝場；勝負由後端確認比分及勝方核對，前端不自行授予勝利。第一批上線後已保存且符合資格的勝場可以計入，不回填舊實驗紀錄。失敗、待確認、撤銷、超額及重複資料不增加勝場。撤銷後重新核對兩項徽章資格。

六項徽章共用原本的兩個顯示入口。此批只更新前端推導、進度與說明，不改政策版本、結案交易、額度、XP 或獎勵；不需要另外部署後端。連勝與逆轉成就留待後續批次。

## 第三批：連勝與逆轉

| 徽章 | 條件 |
| --- | --- |
| 三連勝 | 生涯最佳連勝達 3 場符合資格的 PK |
| 逆轉獵人 | 至少 1 場符合資格的 PK，逐回合曾出現本人 0 分、對手 3 分（0：3），且最終獲勝 |

連勝依帳本的台灣結案日期與當日序號排序，跨房間、跨日累積，不依分頁回傳順序或畫面排列計算。同房間多場使用結案交易分配的各場序號。超額勝場不增加也不中斷，超額敗場仍中斷；具有本版政策但回合證據不完整的場次會中斷。舊版無政策紀錄不參與本版成就。三連勝進度顯示生涯最佳連勝，而非目前連勝。

逆轉重播已經 adapter 核對完整的 `roundsPerspective`，任一有效回合結束後本人累積分數必須為 0、對手累積分數必須為 3，且最終 `isWin` 為真，才認定逆轉。1：3、2：3 後逆轉、平手再獲勝、一路領先及 0：3 後落敗均不計。0：3 可由一筆極限或多筆有效得分形成，不限定得分方式；最終比分可為 4：3、5：3 或 6：3。既有合資格紀錄按新條件重新核對，僅曾一般落後的舊解鎖不保留。此調整只改前端徽章判定與說明，不改結案資料、XP、額度或政策版本。

八項徽章共用完整帳本、原本額度與入口。撤銷後排除撤銷紀錄，按剩餘紀錄重新排序計算（包含最佳連勝），不保存失去證據的解鎖狀態。不增加 XP 或正式階級，也不新增後端欄位或部署要求。

## 展示回饋：解鎖與剩餘進度

未解鎖徽章顯示距離目標還差多少場、勝場、不同對手、最佳連勝或逆轉獲勝；已解鎖顯示已達成。兩個成就入口共用相同進度文字。

玩家正在參與的房間由未完賽轉為雙方結案，且完整帳本核對完成後，結果區顯示本房新解鎖徽章，可按「知道了」收起。比較本房結案序號之前／之後的成就，避免後續賽事造成舊房間提示誤判；單純載入歷史或重新進入已完賽房間不觸發。資料尚未核對不提示，過早的舊帳本結果保留待核對，之後更新戰績可重試。

本機儲存依帳號記錄已提示徽章，用於避免同裝置重複提醒，不作為成就資格、XP 或獎勵依據。帳號切換清除待顯示提示。儲存不可用時當次工作階段仍去重，不阻塞結案或戰績。


## 成就依據與排序

兩個成就入口共用已核對完整帳本。已解鎖優先；未解鎖依完成比例由高到低，同分保留原定義順序。排序不改計算或結案資格。

每張成就可展開解鎖／目前進度依據：場次與勝場里程碑列出達標場次（未達標列最新進度）；廣結戰友列最多五位對手的首次合資格場次；三連勝列出首次達標的三場（未達標列最佳連勝）；逆轉獵人列首場符合 0：3 條件的勝局。每場可展開逐回合累積比分，逆轉依據特別標示觸發回合。所有比分以本人在左、對手在右呈現。只保留有限證據參照，不額外查詢後端。撤銷、未結案、超額與不完整回合資料不充當依據；已解鎖成就撤銷後依剩餘有效資料重算。手機自動同步保留已展開區塊，切換帳號不保留前一帳號的展開狀態。
